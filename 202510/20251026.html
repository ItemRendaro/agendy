# xcode26

iOS 26 SDK以降で必須化されるUISceneライフサイクル（SceneDelegate）への移行について、Qiita記事、WWDC 2025のUIKitセッション、Apple Technical Note TN3187の内容を整理する。

# 概要

  • iOS 26の次のメジャーリリース（iOS 27予定）以降、最新SDKでビルドしたアプリはUISceneライフサイクルを採用していないと起動しなくなる。
  • 複数シーンのサポートは任意だが、シーンライフサイクル自体の導入は必須。
  • 既存アプリは早急に対応が必要。

# 必須化のタイムライン

OSバージョン動作
iOS 18.4 / iPadOS 18.4 / Mac Catalyst 18.4 / tvOS 18.4 / visionOS 2.4警告ログ This process does not adopt UIScene lifecycle. This will become an assert in a future version
iOS 26 / iPadOS 26 / Mac Catalyst 26 / tvOS 26 / visionOS 26警告ログ UIScene lifecycle will soon be required. Failure to adopt will result in an assert in the future
iOS 26の次のメジャーリリース（iOS 27予定）最新SDKでビルドしたアプリは、sceneライフサイクル未採用だと起動しない

WWDC 2025のUIKitセッション「UIKitの新機能」でも、21:57付近のスライドで「UIScene life cycle will be required after iOS 26」と明言されている。従来のUIApplication中心のAPIは非推奨になりつつある。

# Sceneの概念

  • SceneはアプリのUIのインスタンス。ドキュメントベースのアプリでは、各ドキュメントを独立したsceneとして表示できる。
  • 複数ウィンドウやマルチタスクに対応できる、柔軟なアプリの基盤となる。
  • Sceneベースのライフサイクルは、アプリ全体のライフサイクル（プロセスの起動など）と、UIが画面に表示されている期間のライフサイクルを分離する。

# 移行が必要かの判断

TN3187では、次のいずれかに該当するアプリはsceneベースのライフサイクルへの移行が必要としている。

  • Info.plistにUIApplicationSceneManifestキーがない、または構成が定義されていない
  • AppDelegateにapplication(_:configurationForConnecting:options:)を実装していない

# 移行手順

# 1. Info.plistにScene Manifestを追加

Info.plistにUIApplicationSceneManifestキーを追加し、scene構成を定義する。これが最も簡単な採用方法で、アプリがシーンを認識し、scene delegateのクラスが読み込まれるようになる。

  • UISceneConfigurationName：sceneの名称
  • UISceneDelegateClassName：delegateクラス名
  • UISceneStoryboardFile：Storyboardファイル名

複数シーンのサポートは任意。UIApplicationSupportsMultipleScenesをtrueにすると複数のシーンを同時に表示できるが、データモデルをsceneごとに分ける必要があるため慎重に検討する。

# 2. 動的構成が必要な場合

ユーザーアクティビティに応じて異なるシーンを生成する場合は、AppDelegateにapplication(_:configurationForConnecting:options:)を実装してUISceneConfigurationを返す。

# 3. ライフサイクルメソッドをSceneDelegateへ移行

AppDelegateの状態遷移メソッドを、SceneDelegateの対応するメソッドに移す。これにより、アプリの状態遷移をscene単位で処理できるようになる。

AppDelegate（移行前）SceneDelegate（移行後）
applicationDidBecomeActivesceneDidBecomeActive
applicationWillResignActivesceneWillResignActive
applicationDidEnterBackgroundsceneDidEnterBackground
applicationWillEnterForegroundsceneWillEnterForeground

# 4. 古いAPIの置き換え

UIAlertViewはiOS 9.0で非推奨だが、App Delegateではまだ使用できていた。scene移行後はUIAlertControllerに置き換えないとクラッシュする事例がある。

# 5. 移行完了の確認

アプリ起動時に次のログが出なくなれば、移行完了と判断できる。

  • This process does not adopt UIScene lifecycle
  • UIScene lifecycle will soon be required
