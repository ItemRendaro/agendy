# Xcode 27の新機能

Xcode 27はWWDC 2026（2026年6月8日発表）で公開され、変更点が多く全体像をつかみにくい。 主な変更は、エージェント型コーディングの統合、Apple silicon専用化、Swift 6.4の同梱である。

この記事は、Appleのプレスリリース、Xcodeリリースノート、Classmethodの解説記事を整理したテスト用の記事である。

# Xcode 27はApple silicon専用でmacOS Tahoe 26.4以降が必要

項目 内容
対応Mac Apple siliconのみ（Intel Macは非対応）
macOS Xcode 27.0はmacOS Tahoe 26.4以降、Xcode 27.2 beta 2はmacOS Tahoe 26.6以降
Swift Swift 6.4
SDK iOS / iPadOS / macOS / watchOS / tvOS / visionOS 27
実機デバッグ iOS 17以降、tvOS 17以降、watchOS 10以降、visionOS（27.2 beta 2時点）

Apple silicon専用になり、アプリサイズは30%小さくなった。

# エージェントがテストやプレビューで自分の作業を検証できる

Xcode 27は、エージェント型コーディングを全面的に統合した。 Anthropic、Google、OpenAIのエージェントをXcode内で利用できる。

エージェントとの会話では、対話的な計画立案や複数ターンのQ&Aができる。 会話画面は、Markdown、コード変更、プレビューを描画するキャンバスを備える。

エージェントは、次の方法で自身の作業を検証できる。

  • テストの作成と実行
  • Playgroundでの検証
  • プレビューでの見た目の確認
  • 新しいDevice Hub経由のシミュレータ操作

拡張方法は次の3つである。

  • プラグインでのカスタムスキルの追加
  • Model Context Protocol（MCP）によるツール接続
  • Agent Client Protocol対応エージェントの接続

GitHubとFigmaが最初の対応プラグインである。

Xcode 27.2 beta 2では、GetCodeCoverage MCPツールが追加された。 直近のテスト結果のコードカバレッジを返す。

# Foundation Modelsでオンデバイスとクラウドのモデルを同じAPIで扱える

Foundation Modelsフレームワークは、次の3つを1つのSwift APIで扱える。

  • 画像入力に対応したオンデバイスモデル
  • Private Cloud Computeのサーバーモデル
  • カスタムスキル

LanguageModel プロトコルにより、AnthropicやGoogleなどサードパーティのクラウドモデルも利用できる。

Core AIは、カスタムモデルをオンデバイスで実行する新しいフレームワークである。 Apple siliconのユニファイドメモリとNeural Engine向けに最適化されている。

# SwiftUIはコード変更なしで高速化し、Swift 6.4は警告を個別に抑制できる

SwiftUIは、状態の初期化とレイアウト描画が高速化された。 コードの変更は不要である。

SwiftUIには次のAPIが追加された。

  • List 以外のビューでも使える reorderable API
  • ReadableDocument / WritableDocument プロトコル

Swift 6.4では、警告の個別抑制ができるようになった。 anyAppleOS などの簡略化されたavailability属性と、コンパイラ診断の改善も入った。

# ツールバーとテーマを変更でき、JSON形式のプロジェクトに対応した

ツールバーを自由にカスタマイズできるようになった。 エディタ全体に色を適用する、新しいテーマシステムも入った。

Xcode Cloudは最大2倍高速になり、Metalアプリとvisionアプリのビルドに対応した。

Xcode 27.2 beta 2で、JSONベースのプロジェクト形式（.xcproj）に対応した。 読みやすくマージしやすい形式で、File inspectorから有効にする。

# iOS 27 SDKではシーンライフサイクル未採用のアプリが起動しない

非推奨と削除の対象は次のとおりである。

対象 内容
UIKitのシーンライフサイクル iOS 27 SDKでビルドしたアプリは、採用していないと起動しない
UIDesignRequiresCompatibility iOS 27以降向けのビルドでは無視され、Liquid Glassを回避できない
On Demand Resources 非推奨。Background Assetsへ移行する
MXMetricManager 非推奨。AsyncStreamベースの MetricManager へ移行する
ld64リンカ 削除され、-ld_classic オプションも廃止

シーンライフサイクルへの移行手順は、2025年10月の記事「SceneDelegate移行」で扱っている。
