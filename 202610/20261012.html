# xcode27

WWDC 2026（2026年6月8日発表）で公開されたXcode 27について、Appleのプレスリリース、Xcodeリリースノート、Classmethodのベータリリースノート解説記事の内容を整理する。テスト用の記事。

# 概要

  • エージェント型コーディングを全面的に統合し、Anthropic、Google、OpenAIのエージェントをXcode内で利用できる。
  • Apple silicon専用になり、アプリサイズは30%小さくなった。
  • Swift 6.4と、iOS / iPadOS / macOS / watchOS / tvOS / visionOS 27のSDKを同梱する。

# 動作要件

項目内容
対応MacApple siliconのみ（Intel Macは非対応）
macOSXcode 27.0はmacOS Tahoe 26.4以降、Xcode 27.2 beta 2はmacOS Tahoe 26.6以降
SwiftSwift 6.4
実機デバッグiOS 17以降、tvOS 17以降、watchOS 10以降、visionOS（27.2 beta 2時点）

# エージェント型コーディング

  • エージェントとの会話で対話的な計画立案や複数ターンのQ&Aができ、Markdown、コード変更、プレビューを描画するキャンバスを備える。
  • エージェントはテストの作成と実行、Playgroundでの検証、プレビューでの見た目の確認、新しいDevice Hub経由のシミュレータ操作で、自身の作業を検証できる。
  • プラグインでカスタムスキルの追加、Model Context Protocol（MCP）によるツール接続、Agent Client Protocol対応エージェントの接続ができる。GitHubとFigmaが最初の対応プラグイン。
  • Xcode 27.2 beta 2では、直近のテスト結果のコードカバレッジを返すGetCodeCoverage MCPツールが追加された。

# Foundation ModelsとCore AI

  • Foundation Modelsフレームワークは、画像入力に対応したオンデバイスモデル、Private Cloud Computeのサーバーモデル、カスタムスキルを1つのSwift APIで扱える。
  • LanguageModelプロトコルにより、AnthropicやGoogleなどサードパーティのクラウドモデルも利用できる。
  • Core AIは、カスタムモデルをオンデバイスで実行する新フレームワーク。Apple siliconのユニファイドメモリとNeural Engine向けに最適化されている。

# SwiftUIとSwift

  • SwiftUIは状態の初期化とレイアウト描画が高速化され、コード変更は不要。
  • List以外のビューでも使えるreorderable APIと、ReadableDocument / WritableDocumentプロトコルが追加された。
  • Swift 6.4では警告の個別抑制、anyAppleOSなどの簡略化されたavailability属性、コンパイラ診断の改善が入った。

# Xcode本体の変更

  • ツールバーを自由にカスタマイズでき、エディタ全体に色を適用する新しいテーマシステムが入った。
  • Xcode Cloudは最大2倍高速になり、Metalアプリとvisionアプリのビルドに対応した。
  • Xcode 27.2 beta 2で、JSONベースのプロジェクト形式（.xcproj）に対応した。読みやすくマージしやすい形式で、File inspectorから有効にする。

# 非推奨と削除

対象内容
UIKitのシーンライフサイクルiOS 27 SDKでビルドしたアプリは、採用していないと起動しない
UIDesignRequiresCompatibilityiOS 27以降向けのビルドでは無視され、Liquid Glassを回避できない
On Demand Resources非推奨。Background Assetsへ移行する
MXMetricManager非推奨。AsyncStreamベースのMetricManagerへ移行する
ld64リンカ削除され、-ld_classicオプションも廃止

シーンライフサイクルへの移行手順は、2025年10月の記事「SceneDelegate移行」を参照。
