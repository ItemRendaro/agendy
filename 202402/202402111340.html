# vscodeのgithub copilotのキー設定

2024-02-11 14:04:00

VS CodeでGitHub Copilot Chatのコマンドに、どのキーが割り当てられているかを確認したかった。 キーボードショートカット画面を @ext:GitHub.copilot-chat で絞り込むと一覧できる。

# 拡張機能IDで絞り込むとCopilot Chatのコマンドだけが並ぶ

キーボードショートカット画面の検索欄に @ext:GitHub.copilot-chat と入力した結果が次の画面である。

この画面では、「GitHub Copilot: ターミナル コマンドの提案」にだけキーが割り当てられていた。 キーは ⌘ I、条件（いつ）は terminalFocus である。 「これを修正する」「テストを生成する」など、ほかのコマンドにはキーが割り当てられていなかった。
